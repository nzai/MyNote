# ClipNote 测试与验收

本文档用于 Windows 10/11 x64 实机验收。自动化测试不能替代真实托盘、原生保存对话框、DPI 缩放和关机清理行为的检查。

## 自动化验证

在仓库根目录运行：

```powershell
$env:GOCACHE = (Join-Path $PWD ".work\gocache")
go test ./...
go vet ./...
.\scripts\build.ps1
.\bin\clipnote.exe --check
```

如果 PowerShell 禁止执行本地脚本，请把构建命令替换为：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1
```

预期：

- 所有 Go 测试通过。
- `go vet` 无诊断。
- 生成 `bin\clipnote.exe`。
- `--check` 输出 `version`、`executable`、`log_dir`、`log_file`、`cache_dir`、`config_file` 以及当前限制值，退出码为 0。

可选的 Win32 窗口冒烟测试会真实创建本机窗口：

```powershell
$env:CLIPNOTE_GUI_TEST = "1"
go test ./internal/ui -run TestCreateDocumentWindows -count=1 -v
```

在没有交互桌面或没有可用 `Shell_TrayWnd` 的自动化环境中，托盘测试会跳过。跳过不等于通过。

## 启动与托盘

1. 启动 `bin\clipnote.exe`，确认右侧系统托盘出现 ClipNote 图标，且没有多余控制台窗口。
2. 再次启动同一个可执行文件，确认没有第二个托盘图标；已运行实例会打开当前剪贴板窗口。
3. 左键单击托盘图标一次，确认只出现一个窗口，标题栏无菜单栏。
4. 确认标题栏依次显示应用图标、标题、紧贴标题的保存图标，关闭图标固定在右上角。
5. 右键单击托盘图标，确认菜单包含“打开当前剪贴板”“打开缓存文件夹”“清空临时缓存”“退出”。
6. 关闭所有剪贴板窗口，确认托盘图标和进程仍在运行。

## 文本捕获与窗口独立性

1. 从其他程序复制一段中文和英文混合文本。
2. 连续左键单击托盘图标 3 次。
3. 确认出现 3 个独立窗口，并以级联方式错开。
4. 确认 3 个窗口都显示相同内容，但可以分别编辑。
5. 修改其中一个窗口，确认另外两个窗口内容不变。
6. 检查缓存目录，确认有 3 个独立记录目录，ID 不重复。
7. 在缓存状态尚未变成“已缓存”时观察窗口，确认窗口已经可见、可聚焦并且可以编辑。

## 图片捕获

1. 从截图工具或其他程序复制一张图片。
2. 单击托盘图标。
3. 确认新窗口显示图片，保持宽高比，并在缩放窗口时重新适配。
4. 确认图片内容不可编辑。
5. 按 `Ctrl+S`，确认出现 Windows 原生“另存为”对话框。
6. 使用 `.png` 扩展名保存，打开保存结果确认图片完整。

## 保存与脏状态

1. 在文本窗口输入一个字符，确认标题出现 `*`。
2. 按 `Ctrl+S`，确认出现原生“另存为”对话框。
3. 取消对话框，确认窗口仍为脏状态，标题仍有 `*`。
4. 再次按 `Ctrl+S`，选择路径保存，确认标题中的 `*` 消失。
5. 再编辑文本，按 `Ctrl+S`，确认直接覆盖刚才的文件，不再弹对话框。
6. 按 `Ctrl+Shift+S`，确认弹出“另存为”并保存出第二份副本。
7. 按住 `Shift` 单击标题右侧的保存图标，确认行为同样是“另存为”。
8. 保存过程中继续编辑，确认保存完成后新的修改仍保留 `*`。

## 关闭确认

1. 关闭没有修改的文本窗口，确认不弹确认框，直接关闭。
2. 修改文本后点击右上角关闭图标，确认出现“保存 / 不保存 / 取消”。
3. 选择“取消”，确认窗口保留、内容未丢失。
4. 再次关闭并选择“不保存”，确认窗口关闭且没有写出新文件。
5. 再次修改并关闭，选择“保存”。保存对话框取消或写入失败时，确认窗口保持打开。
6. 保存成功后确认窗口自动关闭。

## 退出与缓存清理

1. 创建一个窗口并在保存对话框中选择目标文件，确认保存开始。
2. 从托盘菜单选择“退出”，确认程序等待保存进入安全点，而不是立即丢窗口或留下半写文件。
3. 在异步保存已经开始时修改文本，再选择退出；如果保存完成后仍有新修改，确认程序会再次要求处理未保存内容。
4. 在退出确认中选择“取消”，确认程序继续驻留托盘，不会稍后自行退出。
5. 在缓存写入进行时退出，确认退出后缓存目录中没有 `.partial-*` 目录。
6. 托盘菜单选择“打开缓存文件夹”，确认打开的是 `%LOCALAPPDATA%\ClipNote\cache`。
7. 托盘菜单选择“清空临时缓存”，先取消一次确认目录内容未变，再确认清空。
8. 确认清空缓存不会删除手动保存到其他位置的文件。

## 窗口行为与 DPI

1. 拖动标题栏，确认窗口移动。
2. 拖动窗口边缘和四角，确认可以缩放，且内容与状态栏布局正确。
3. 双击标题栏，确认窗口最大化；再次双击恢复。
4. 在 100% 和 150% 或 200% DPI 显示器之间拖动窗口，确认标题栏、图标、字体和编辑区域没有明显错位。
5. 连续打开超过工作区可容纳数量的窗口，确认级联位置在工作区内循环，不把新窗口放到屏幕外。
6. 打开短文本且不换行的内容时，确认编辑区域没有横、纵滚动条。
7. 输入超宽单行或超长多行内容，确认只显示实际需要的横向或纵向滚动条。
8. 切换窗口焦点，确认窗口外围不会出现额外的选中边框或焦点框。

## 快捷键

1. 文本窗口按 `Ctrl+A`，确认全选编辑框文本。
2. 按 `Ctrl+S`，确认执行保存。
3. 按 `Ctrl+Shift+S`，确认执行另存为。
4. 按 `Ctrl+W`，确认关闭当前窗口并遵守未保存确认。
5. 按 `Alt+F4`，确认行为与关闭当前窗口一致。

## 失败与限制

1. 复制超过配置上限的文本，点击托盘，确认不创建空窗口，并显示错误提示。
2. 复制无法解码的图片数据，点击托盘，确认不创建窗口，并记录完整错误上下文。
3. 将 `ui.progress_delay_ms` 调大，确认快速缓存完成后不闪出进度提示。
4. 将 `ui.progress_delay_ms` 调小并写入较大内容，确认超过阈值后显示进度和“取消”。
5. 在进度显示后点击“取消”，确认窗口仍可用；缓存状态表示已取消，缓存目录没有本次的未完成记录。

## 日志与检查

1. 运行 `clipnote.exe --check`，记录输出的实际日志、缓存和配置路径。
2. 使用 `--debug=cache,ui,clipboard` 启动，操作托盘和窗口，确认对应范围有 debug 日志，其他范围没有批量 debug 输出。
3. 检查日志为 JSON Lines，每行包含时间、级别、范围和任务标识。
4. 搜索日志，确认没有出现剪贴板正文或图片二进制内容。
5. 让程序目录不可写或把程序放在无写权限目录，确认日志回退到 `%LOCALAPPDATA%\ClipNote\logs`，且 `--check` 报告实际路径。
6. 检查日志轮转配置生效，单个日志文件不会无限增长。
